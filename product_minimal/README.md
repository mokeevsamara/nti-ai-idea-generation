# product_minimal — набор промптов для обычного чата (контур-минимум)

Вариант агента для чатов без агентного режима (без файлов, инструментов, памяти между сессиями): только промпты + веб-поиск браузера пользователя. Каждый шаг маршрута — отдельный самодостаточный промпт; артефакты между шагами пользователь переносит вручную (копирует текст из чата в чат).

## Как пользоваться

1. Для каждого шага открой **новый чат** и вставь соответствующий промпт из `prompts/` первым сообщением.
2. Модель-калибровка: промпты рассчитаны на крупные чаты класса DeepSeek/GPT/GLM (правило: работает на DeepSeek — работает и в других).
3. Артефакты переноси сам: в конце каждого шага чат выдаёт готовый текст — сохрани его (файлом или заметкой) и вставь в следующий чат по требованию промпта.
4. Шаги конвейера организатора — с возвратом в чат 01:
   - чат 1: `01-шаг0-контекст` — извлекает основы из паспорта АП, выдаёт «Контекст для поиска»;
   - чат 2: `02-шаг0-глубокий-поиск` — выполняет поиск, выдаёт «Итоги глубокого поиска»;
   - **возврат в чат 1**: вставить итоги — чат 01 собирает «Пакет основ для Шага 1»;
   - чат 3: `03-шаг1-задачи` — вставить промпт + Пакет основ; генерация после «переходим».
   Конвейер команды (отдельные чаты, от выбранной задачи): `04-упаковка` → `05-оптимист` → `06-пессимист` → `07-переупаковка` → `08-пакет-трекера`.

## Ключевые отличия от агентной версии (product_v2)

- Шаг 0 разделён на два промпта: извлечение контекста из документов и глубокий поиск. Поиск в шаге 0b чат выполняет **сам** своим инструментом веб-поиска (websearch «из коробки»); режим «человек ищет» — только если в среде поиска нет.
- Финал шага 0a — самодостаточный блок «Контекст для поиска»: копируется целиком в новый чат вместе с промптом 02; проверочный вызов Yandex API исключён (поисковый слой — средства чата).
- Фасилитация упаковки сохранена: вопросы по блокам полей, без сочинения за команду.
- Лимиты: длинные документы вставляй в чат частями (обычный чат держит меньше контекста, чем агентная среда).

## Состав

| Промпт | Шаг | Роль | Вход | Выход |
|---|---|---|---|---|
| `01-шаг0-контекст.md` | Шаг 0a | организатор | паспорт АП (+ основы) + возврат итогов поиска | «Контекст для поиска»; после возврата — «Пакет основ для Шага 1» (03/04/05/06) |
| `02-шаг0-глубокий-поиск.md` | Шаг 0b | организатор | «Контекст для поиска» из 01 (целиком) | «Итоги глубокого поиска» — возвращаются в чат 01 |
| `03-шаг1-задачи.md` | Шаг 1 | организатор | пакет 0-context (текстами) | проектные задачи с валидацией + сводка портфеля |
| `04-упаковка.md` | Шаг 2a | команда | выбранная задача | первичный паспорт проекта |
| `05-оптимист.md` | Шаг 2b | команда | паспорт проекта | отчёт технооптимиста |
| `06-пессимист.md` | Шаг 2c | команда | паспорт проекта | отчёт технопессимиста |
| `07-переупаковка.md` | Шаг 2d | команда | паспорт + оба отчёта | список улучшений + решения + обновлённый паспорт |
| `08-пакет-трекера.md` | Шаг 2e | команда | паспорт + отчёты + резюме | пакет для трекера |

## Статус сборки

Собрано вручную из `product_v2/` (скиллы + шаблоны): каждый промпт = роль шага + инлайн-шаблон артефакта + регламент переноса. При изменении скиллов product_v2 промпты пересматриваются. Роли физически разделяются: конвейер организатора и конвейер команды — разные чаты.
