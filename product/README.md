# ИИ-агент «Генерация проектных задач и упаковка идей» для акселерационных программ

Отчуждаемый пакет альфа-версии (0.1). Язык работы — русский.

Агент сопровождает акселерационную программу по методике «ИИ-ассистируемая генерация идей»: готовит контекст (Шаг 0), генерирует и валидирует проектные задачи (Шаг 1), ведёт студенческую команду от выбранной задачи до первичного паспорта проекта и пакета для трекера (Шаг 2). Методическое описание процесса передаётся заказчику отдельным документом («Методика ИИ-ассистируемой генерации идей»); данный пакет самодостаточен для работы агента.

## Состав пакета

- `AGENTS.md` — контракт агента: роли, маршрут, правила, команды. Прочитайте первым.
- `skills/` — 9 скиллов шагов (каждый — папка с SKILL.md: name + описание-триггер «использовать, когда...»); среды с поддержкой скиллов подхватывают их автоматически, остальные — по карте маршрута в контракте.
- `templates/` — 12 шаблонов артефактов (01–12), на них ссылаются скиллы.
- `instructions/deploy-agent.md` — как развернуть агента в агентной среде.
- `instructions/deep-research.md` — отчуждаемая процедура глубокого поиска (поисковый слой: Yandex Search API — основной механизм; веер запросов, иерархия источников, правило двух опор) для Шага 0.
- `research/` — материалы пилота барьерной карты: рецепт Yandex Search API (нужен агенту при глубоком поиске), барьерная карта v2 (референс формата), сводки доборов. Контрактом не являются.

## Быстрый старт (smoke-инструкция)

Проверка, что пакет работает на чистой машине, — 3 команды:

1. Скопируйте папку пакета целиком как рабочую папку и откройте в агентной среде (ZCode, DeepSeek harness, OpenWebUI-агент, Goose). Подробности: `instructions/deploy-agent.md`.
2. Первая команда агенту: **«Роль: организатор»**. Затем загрузите паспорт АП (файлом или текстом) и скажите: **«Шаг 0»**. Агент извлечёт параметры заявки, разложит основы, проверит достаточность и доберёт недостающее глубоким поиском.
3. После закрытия Шага 0: **«Шаг 1»** — агент сгенерирует проектные задачи в рамке четырёх основ и валидирует каждую по 5 критериям. Для роли команды (упаковка выбранной задачи) — новая сессия, **«Роль: команда»** → «Упаковка».

Если агент не понял команду — дайте ему: «Прочитай AGENTS.md и действуй по нему» (Goose и подобные среды не подхватывают контракт автоматически).

## Референс-модель калибровки

Пакет проверен на GLM (ZCode): полный маршрут Шаг 0 → Шаг 1 (45 задач) → валидация → Шаг 2 (упаковка → оптимист → пессимист → переупаковка → пакет трекеру) пройден на данных пилотного заказчика 08–09.10.2026; уроки внесены в скиллы.

## Примечания

- Состав загружаемых в агента данных определяет заказчик.
- Поисковый слой Шага 0: основной механизм — Yandex Search API (ключ организатора, рецепт в `research/`); без ключа агент выдаёт веер запросов и план ручного сбора. Нативный веб-поиск среды — опциональный дополнительный канал.
