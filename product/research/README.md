## Контекст пилота

Пилот проверял барьерный слой дип-ресерча (каналы В1–В7 из `product/instructions/deep-research.md`) на одном направлении — нацпроект «Средства производства и автоматизации»: сколько барьерных строк собирается за проход без человека. Итог: 15 строк (прогон 1, WebSearch) → 18 строк/7 confirmed (Serper-ретест) → карта v2 с верифицированными числами (Yandex-добор + ручная сверка). Полная история и уроки — в памяти сессии (memory: pilot-barrier-map-status) и в сводках.

## Ключевые уроки (для методики deep-research)

1. **Сиды задания подлежат проверке**: сид-приказы № 811/975/2300 оказались методиками чужих нацпроектов (транспортная мобильность, код B) — в рамку не включать без верификации.
2. **Поисковые слои**: Serper (Google) — основной; Yandex Search API — добор по РФ-тематике (нашёл то, что Serper пропустил: приказы-методики, databudget-карточки); WebSearch субагентов зависит от провайдера модели; поисковые формы legalacts/К+/cntd программно мертвы — работают точечные URL.
3. **Эшелоны доступности**: КонсультантПлюс отдаёт полные тексты только рабочими днями 20:00–24:00 МСК; zakupki.gov.ru/ЕИС — connect timeout; gisp.gov.ru, нтр.рф — 403; PDF-паспорта отдаются как octet-stream, но читаются pypdf; rosstat требует `curl -k` (сертификат).
4. **Числа «база→цель»**: карточки ЕПБС/DataBudget (databudget.ru) отдают полные годовые ряды и версии паспортов — это первоисточник чисел, а не вторичные обзоры; сверять ряд databudget с PDF-паспортом ФП (могут расходиться — приоритет у более свежей ЕПБС).
5. **Агентам веб-исследований задавать явный бюджет вызовов** (20 поисково-открытий на канал — впритык).

## Как продолжить в новом чате

1. Прочитать этот README + `барьерная-карта-СПА-v2-0810.md` (шапки файлов описывают назначение каждого).
2. Память проекта (memory pilot-barrier-map-status) — статус, уроки, правила согласования.
3. Следующий шаг по плану — генерация 5–7 задач по карте (барьер × задел КИУ × сегмент Нейронет) — по явной команде А.М.
