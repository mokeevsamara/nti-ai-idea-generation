## Контекст пилота

Пилот проверял барьерный слой глубокого поиска (каналы В1–В7 из `product/instructions/deep-research.md`) на одном направлении — нацпроект «Средства производства и автоматизации»: сколько барьерных строк собирается за проход без человека. Итог: 15 строк (прогон 1, WebSearch) → 18 строк/7 confirmed (Serper-ретест) → карта v2 с верифицированными числами (Yandex-добор + ручная сверка). Полная история и уроки — в памяти сессии (memory: pilot-barrier-map-status) и в сводках.

## Ключевые уроки (для методики deep-research; решения зафиксированы 08.10.2026 в AGENTS.md воркспейса и instructions/deep-research.md)

1. **Стартовые подсказки задания подлежат проверке**: подсказки-приказы № 811/975/2300 оказались методиками чужих нацпроектов (транспортная мобильность, код B) — в рамку не включать без верификации; доверенный источник перечня методик — сводники Росстата FP0*_N.htm.
2. **Поисковые слои (решение)**: основной механизм — Yandex Search API v2 напрямую (рецепт в этой папке); Serper (Google) непригоден как основной — гос. сайты и правовые базы лочат Google-краулер по IP, искажение системное («работает, но молча собирает дыры»); WebSearch субагентов зависит от провайдера модели и непереносим; нативный поиск — опциональный доп. канал; MCP — опция среды, не контракт. Поисковые формы legalacts/К+/cntd программно мертвы — работают точечные URL.
3. **Проверочный вызов ключа перед сбором; бюджет — квотами по каналам В1–В7**, не сквозным счётчиком (20 поисково-открытий впритык — канал методик съел бюджет остальным; fedstat/ЕМИСС/форма 1-робототехника не дошли).
4. **Эшелоны доступности**: КонсультантПлюс отдаёт полные тексты только рабочими днями 20:00–24:00 МСК; zakupki.gov.ru/ЕИС — connect timeout; gisp.gov.ru, нтр.рф — 403; PDF-паспорта отдаются как octet-stream, но читаются pypdf; rosstat требует `curl -k` (сертификат). Карта доступности — в instructions/deep-research.md (снимок 08.10.2026).
5. **Числа «база→цель»**: карточки ЕПБС/DataBudget (databudget.ru) отдают полные годовые ряды и версии паспортов — это первоисточник чисел, а не вторичные обзоры; сверять ряд databudget с PDF-паспортом ФП (могут расходиться — приоритет у более свежей ЕПБС). Формулы в приказах — изображениями: восстанавливать по описаниям символов + сверять с PDF методик Росстата (MET_N_*.pdf).
6. **Индустриальные опоры**: прямые закупки программно закрыты — собирать из мер поддержки (ГИСП — браузерный эшелон), корпоративных программ через вторичные публикации, ассоциаций («Станкоинструмент», НАУРР); косвенная опора не конфирмирует барьер.
