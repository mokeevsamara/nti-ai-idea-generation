# Развёртывание агента

## Агентная среда

Подходит для сред, которые умеют читать файлы рабочей папки: ZCode, DeepSeek harness, OpenWebUI-агент, Goose и аналогичные.

1. Скопируйте пакет (эту папку) целиком на машину/в окружение, где работает агент. Она становится рабочей папкой проекта.
2. Откройте эту папку в среде. Если среда подхватывает `AGENTS.md` автоматически (ZCode и большинство современных харнесов) — больше ничего не нужно. Если нет — первой командой дайте агенту: «Прочитай AGENTS.md и действуй по нему».
3. Начните: «Роль: организатор» → «Шаг 0» (загрузите паспорт АП) — или «Роль: команда» → «Валидация идеи» / «Упаковка».
4. Состояние работы агент ведёт в `workspace/` — не удаляйте её между сессиями.

Требования к среде: доступ к файлам рабочей папки (чтение и запись) — желателен; веб-поиск — желателен (нужен для дип-ресерча Шага 0; без него агент выдаст план поиска по instructions/deep-research.md).

## Референс-модель

Пакет проверен на GLM (ZCode). Первый внешний прогон (октябрь 2026): Goose + DeepSeek (routerai.ru) — маршрут Шаг 0 → Шаг 1 пройден полностью на реальных данных, находки учтены в разделе ниже.

## Известные особенности сред

- Если среда ожидает файл контракта с именем `agent.md` (или иным), переименуйте `AGENTS.md` — содержимому переименование не нужно.
- Если среда не умеет работать с файлами рабочей папки — этот пакет для неё не предназначен; используйте поставку, рассчитанную на ваш тип среды.
- Goose: контракт не подхватывается автоматически — первой командой дайте агенту прочитать `AGENTS.md`. Инструменты командной строки Windows (`type`, `dir`) ломают кириллицу — файлы читать/писать через PowerShell с `-Encoding UTF8`. Фоновые субагенты с веб-поиском могут зависать или возвращать заглушки — агент действует по fallback дип-ресерча (`instructions/deep-research.md`).
- Лёгкие (flash) модели могут пропускать обязательные артефакты шага (замечено: сводка портфеля `00-…` в `workspace/1-tasks/` после Шага 1) и ставить «✅» в чек-листах без фактической проверки. Проверяйте состав `workspace/` по таблице маршрута (команда «Статус») и требуйте от агента подтверждения проверок содержимым, не галочкой.
- Чат-среды без доступа к файлам — этот пакет для них не предназначен; артефакты чат-форка переносятся копипастой по его регламенту.
