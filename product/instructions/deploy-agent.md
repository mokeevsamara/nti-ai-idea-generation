# Развёртывание агента

## Сценарий 1. Агентная среда (основной)

Подходит для сред, которые умеют читать файлы рабочей папки: ZCode, DeepSeek harness, OpenWebUI-агент, Goose и аналогичные.

1. Скопируйте папку `product/` целиком на машину/в окружение, где работает агент. Папка становится рабочей папкой проекта.
2. Откройте эту папку в среде. Если среда подхватывает `AGENTS.md` автоматически (ZCode и большинство современных харнесов) — больше ничего не нужно. Если нет — первой командой дайте агенту: «Прочитай AGENTS.md и действуй по нему».
3. Начните: «Роль: организатор» → «Шаг 0» (загрузите паспорт АП) — или «Роль: команда» → «Валидация идеи» / «Упаковка».
4. Состояние работы агент ведёт в `workspace/` — не удаляйте её между сессиями.

Требования к среде: доступ к файлам рабочей папки (чтение и запись) — желателен; веб-поиск — желателен (нужен для дип-ресерча Шага 0; без него агент выдаст план поиска по instructions/deep-research.md).

## Сценарий 2. Обычный чат без файловой работы

Среда умеет только диалог (нет файлов, нет инструментов). Используйте чат-форк пакета — папку `product_minimal/`: каждый шаг свёрнут в отдельный самодостаточный промпт, артефакты между чатами вы переносите вручную по карте маршрута. Подробности — в README этой папки.

## Референс-модели

- Агентный контур: проверен на GLM (ZCode).
- Чат-форк: калибруется на DeepSeek-V4 (онлайн, бесплатно). Правило переноса: «работает на DeepSeek-V4 — работает и в других крупных чатах».

## Известные особенности сред

- Если среда ожидает файл контракта с именем `agent.md` (или иным), переименуйте `AGENTS.md` — содержимому переименование не нужно.
- Если среда не создаёт папки — создайте `workspace/` вручную по схеме из AGENTS.md, либо ведите артефакты как отдельные сообщения/документы чата (форк-режим).
