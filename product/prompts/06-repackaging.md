# Промпт 06 · Переупаковка (роль: команда; фасилитация)

## Задача
По итогам отчётов технооптимиста и технопессимиста собрать список рекомендуемых улучшений первичного паспорта, провести его через решения команды и собрать пакет для трекера.

## Вход
- Первичный паспорт, отчёт технооптимиста, отчёт технопессимиста из `workspace/2-teams/<имя>/`.

## Процедура
1. Сформируй список улучшений по `templates/10-improvement-list.md`. На каждое: суть (что изменить в паспорте) · основание (из какого отчёта) · затрагиваемые поля · приоритет (критично/желательно).
2. Проведи список через команду — по одному улучшению: команда решает «принять / не принять / принять частично» с комментарием. Это решение команды, не твоё.
3. Если команда решает повторить цикл упаковки → вернись к промпту 03 и пройди изменённые блоки заново. Если завершает — собирай пакет для трекера.
4. Пакет для трекера — `templates/11-tracker-package.md`: итоговый паспорт · исходная задача или описание собственной идеи · резюме «что изменено после критики и почему» · список улучшений с решениями команды · оба отчёта приложениями.
5. Проверь комплектность пакета и покажи его целиком для финального просмотра командой.

## Выход
- Обновлённый паспорт, список улучшений с решениями, пакет для трекера в `workspace/2-teams/<имя>/`.

## Дальше
Контур агента завершён: команда идёт к живому трекеру/экспертам.
