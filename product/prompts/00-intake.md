# Промпт 00 · Шаг 0 — приём контекста (роль: организатор)

## Задача
Собрать пакет контекста для генерации проектных задач: заявка организатора + четыре основы (паспорт АП, рамка приоритетов, реестр запросов индустриальных партнёров, НТЗ вуза). Проверить достаточность, недостающее добрать глубоким поиском.

## Вход
- Паспорт АП — обязательный документ, его не может не быть. Если не загружен — запроси и жди.
- Предъявленные основы (любые могут отсутствовать): рамка приоритетов, реестр запросов партнёров, НТЗ вуза.
- Требуемое число проектных задач. По умолчанию — число команд АП + 15% (округлить вверх); организатор может указать другое.

## Процедура
1. Извлеки параметры заявки из паспорта АП и заполни `templates/03-organizer-request.md`. Всё, чего в паспорте нет, — пометь и запроси у организатора. Кастомизация параметров — только по его явному указанию.
2. Принятые основы разложи по шаблонам: рамка приоритетов — `templates/04-priorities-frame.md`, реестр партнёров — `templates/05-partner-requests-registry.md`, НТЗ — `templates/06-university-research-base.md`. Папка `workspace/0-context/`.
3. Прогони `templates/07-context-sufficiency-checklist.md` блок за блоком; результат — протокол проверки достаточности: что предъявлено и полно, что предъявлено с пробелами, чего нет.
4. Пробелы закрой глубоким поиском по `instructions/deep-research.md` (веер запросов, иерархия источников, правило двух опор, проверка статус/дата/редакция каждого источника).
5. Рамка приоритетов: в паспорте АП обычно есть только рынки НТИ и сквозные технологии — явно пометь «это сырьё рамки, не рамка приоритетов», дострой карту приоритетов по направлению и покажи организатору разрыв: «было в паспорте → добавлено из источников».
6. Всё найденное поиском отдай на подтверждение организатора до использования на следующих шагах.
7. Покажи итоговый состав `workspace/0-context/` и переходи к Шагу 1.

## Границы
- Не фантазируй приоритеты, данные вуза и партнёров; каждое утверждение — с источником.
- Не требуй чувствительных сведений; состав загружаемых данных определяет организатор.
- Не генерируй задачи на этом шаге.
