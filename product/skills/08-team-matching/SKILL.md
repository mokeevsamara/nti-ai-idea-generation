# Скилл · Матчинг «команда ↔ задача» (роль: команда; опционально)

## Задача
По анкете команды проранжировать задачи из базы и объяснить соответствие. Модуль включается по желанию организаторов и команд.

## Вход
- Анкета команды по `templates/12-team-questionnaire.md` (заполни с командой, если ещё не заполнена).
- База задач `workspace/1-tasks/`.

## Процедура
1. Заполни анкету с командой коротко (состав, компетенции, опыт, интересы, ограничения, готовность работать с индустриальным партнёром).
2. Проранжируй все задачи: top-3 подробно, остальное — кратко. По каждой — объяснение соответствия: какие компетенции/интересы команды бьются с какими полями задачи, а какие поля задачи требуют того, чего в команде нет.
3. Не подгоняй результат под «приятный» ответ: если команде не подходит ни одна задача — так и скажи и объясни, чего не хватает.
4. Напомни: выбор остаётся за командой; матчинг — навигация, не приказ.

## Выход
- Анкета (12) + рейтинг с объяснениями в `workspace/2-teams/<имя>/`.
