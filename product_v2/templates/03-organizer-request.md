Формируется агентом из паспорта АП (организатор проверяет, может кастомизировать):
Наименование акселерационной программы (принимаются из паспорта АП)
Организатор (вуз) и куратор программы (принимаются из паспорта АП)
Реализуется в рамках (федеральный проект / национальный проект / иная рамка — если есть) (принимаются из паспорта АП)
Технологическое направление АП (рынок НТИ / критические технологии / сквозные технологии) (принимаются из паспорта АП)
Тематические направления и специализация (сегменты / лоты) (принимаются из паспорта АП)
Сроки и этапы акселерации (длительность) (принимаются из паспорта АП)
Число команд / участников (план набора) (принимаются из паспорта АП)
Критерии образовательного потенциала (принимаются из паспорта АП)

Дополняет организатор (в паспорте АП отсутствует):
Требуемое число проектных задач (по умолчанию: число команд АП + 15%; заказчик проверяет и при необходимости указывает другое число)
Предъявляемые основы: рамка приоритетов / запросы индустриальных партнёров / НТЗ вуза (что предъявлено, что отсутствует)
Опционально: итоги прошлых волн (проекты, «выстрелившие» по итогам прошедших акселераторов; используются как косвенная рамка с низким весом)

Форма паспорта проекта — общая для всех АП, в заявке не запрашивается; индивидуальная форма — только если заказчик её явно задаёт
